# Kitchen Inventory 

## Description
A simple Python program that tracks kitchen ingredients and allows users to check available stock and use eggs when preparing a fried egg.

## Features
- Tracks eggs, flour, and sugar.
- Displays the total number of kitchen items.
- Checks whether enough eggs are available.
- Updates the egg count after use.
- Displays messages based on ingredient availability.

## How to Run
1. Save the code in a file named `kitchen_inventory.py`.
2. Run the following command in your terminal:

   ```bash
   python3 kitchen_stock.py
   ```
